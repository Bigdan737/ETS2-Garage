# ETS2 Garage

Редактор профилей Euro Truck Simulator 2 для Windows x64. Здесь публикуются готовые сборки и обновления.

[Скачать последнюю версию](https://github.com/Bigdan737/ETS2-Garage/releases/latest)

1. Скачай архив **ETS2-Garage-X.Y.Z-win-x64.zip**.
2. Распакуй его целиком и запусти **ETS2 Garage.exe**.
3. Оставь папки **ui** и **tools** рядом с приложением. Для запуска нужен Microsoft Edge WebView2 Runtime.

## Обновления

Приложение проверяет новые версии при запуске. Если обновление найдено, нажми кнопку в верхней панели и выбери «Установить и перезапустить».

## Как опубликовать новую версию

1. Собери приложение с новой версией, например **0.2.2**.
2. Создай обычный GitHub Release с тегом **v0.2.2**. Добавь краткое описание изменений.
3. Прикрепи **ETS2-Garage-0.2.2-win-x64.zip** со структурой, как у текущего релиза.
4. Опубликуй релиз после загрузки архива. GitHub должен вернуть SHA-256 прикреплённого файла, чтобы приложение могло проверить загрузку.
